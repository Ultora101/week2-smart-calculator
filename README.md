# Smart Calculator with Search

## Features

- Basic arithmetic operations
- Equation solver using search algorithms
- Visualization of search process
- Interactive menu system

## How Search Works in This Calculator

The searched takes a number range for possible x values and attempts to solve the problem by itterating through the range. Then it measures how close the result is to the target. Once the target is in acceptable range then it can bring it back to the user.

## How to Run

1. Clone the repository
2. Run: `python calculator_with_search.py`
3. Follow the menu options

## Sample Equations to Try

- x + 5 = 10 (answer: 5)
- x \* 3 = 21 (answer: 7)
- 100 - x = 75 (answer: 25)
